# ETF シグナル・ウォッチ

ETFの買い時・売り時を毎日自動チェックし、iPhoneに通知するための個人用ツールです。
GitHub Actions が毎日指標を計算し、GitHub Pages 上のページとJSONを更新します。
iPhoneのショートカット(オートメーション)がそのJSONを定期的にチェックして通知を出します。

## 参照している指標

- 52週高値からの下落率
- 200日移動平均線からの乖離率
- RSI(14)
- CCI(20)
- MACDのゴールデンクロス/デッドクロス
- PER(取得できる銘柄のみ、ETFは取得できないことが多いです)

これらを組み合わせてスコアリングし、「買い」「売り」「様子見」を判定します(`scripts/analyze.py` 内のロジックはお好みで調整可能です)。

## セットアップ手順

### 1. GitHubリポジトリを作成

iPadやiPhoneのブラウザから github.com にアクセスし、新しいリポジトリ(例: `etf-alert`)を作成します。
このフォルダの中身一式をそのリポジトリにアップロードしてください
(PCが無い場合は、GitHubのWeb UIの「Add file → Upload files」で全ファイルをドラッグ&ドロップできます)。

### 2. GitHub Pagesを有効化

リポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `root` に設定します。
数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でページが公開されます。

### 3. GitHub Actionsを有効化

`.github/workflows/daily.yml` が入っていれば自動的にActionsタブに表示されます。
**Actions** タブを開き、ワークフローを一度手動実行(`Run workflow`)して `signals.json` が正しく更新されるか確認してください。
初期状態では UTC 22:30(日本時間 翌7:30)に毎日自動実行されます。時刻を変えたい場合は `daily.yml` の `cron` を編集してください。

### 4. Personal Access Token(銘柄追加用)

ページ上で銘柄を追加/削除するには、GitHubの個人アクセストークンが必要です。

1. GitHubの **Settings → Developer settings → Personal access tokens → Fine-grained tokens** で新規作成
2. 対象リポジトリのみに絞り、`Contents: Read and write` 権限を付与
3. 発行されたトークンを、公開ページの「GitHub連携の設定」欄に、ユーザー名・リポジトリ名とあわせて入力して保存

トークンはその端末のブラウザ内だけに保存され、GitHub API呼び出し以外には使われません。

## iPhoneショートカットの設定(通知を受け取る)

GitHub PagesとActionsだけでは端末への通知(プッシュ通知)は送れないため、iPhone側の「ショートカット」アプリで
**定期的にJSONを取得して通知を表示する**仕組みを作ります。

### ショートカット本体を作る

1. 「ショートカット」アプリ → 「+」で新規ショートカット作成
2. 「URLの内容を取得」アクションを追加し、URLに次を入力:
   `https://<ユーザー名>.github.io/<リポジトリ名>/signals.json`
3. 「辞書から取得」または「JSONを解析」アクションで内容を辞書化
4. `has_active_signal` の値を取得し、「もし」アクションで `true` かどうかを判定
5. `true` の場合:
   - `results` を繰り返し処理し、`signal` が `buy` または `sell` の銘柄だけを抽出
   - 銘柄名・シグナル種別・理由(`reasons_buy` / `reasons_sell`)をテキストに整形
   - 「通知を表示」アクションでその内容を通知
6. `false` の場合は何もしない(または「何もしない」で終了)

同じシグナルを毎日通知しないようにしたい場合は、「ファイルを取得」「ファイルを保存」アクションを使い、
前回チェック時の `updated_at` をiCloud上の小さなテキストファイルに保存し、値が変わった時だけ通知する、という形にすると良いです。

### 自動実行(オートメーション)を設定

1. 「ショートカット」アプリ → 「オートメーション」タブ → 「+」
2. 「時刻」を選択し、Actionsの実行時刻より後(例: 日本時間 8:00)を指定、「繰り返し: 毎日」に設定
3. 実行するショートカットとして、上で作った「ETFシグナル通知」を選択
4. 「実行前に確認」を **オフ** にすると、バックグラウンドで自動実行され、条件を満たした時だけ通知が届きます

iPadでも同じ手順でオートメーションを組めるので、両方の端末に設定しておくと安心です。

## 銘柄の追加方法

公開ページ(`index.html`)の「ウォッチ銘柄の管理」から、ティッカーシンボルを入力して追加できます。

- 東証ETF: `1557.T` のように末尾に `.T` を付ける
- 米国ETF: `VOO`、`VT` のようにそのまま

追加後、次回のActions実行(手動実行も可能)で `signals.json` に反映されます。

## ロジックのカスタマイズ

`scripts/analyze.py` の「スコアリング」部分を編集すると、シグナル判定の閾値や条件を自由に変更できます。
例えば「下落率-15%」を「-10%」に緩めたり、出来高やボリンジャーバンドなど別の指標を追加することも可能です。

## 注意事項

- 投資信託(非上場)は本ツールでは未対応です(価格データの安定した無料取得手段がないため)。将来的にETFと同様の仕組みで対応を検討できます。
- 本ツールは情報提供を目的としたものであり、投資判断は自己責任で行ってください。
- yfinanceは非公式のデータ取得ライブラリのため、まれにデータ取得に失敗することがあります。
